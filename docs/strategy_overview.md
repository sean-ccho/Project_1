### Quantitative Stock Screener — 어떻게 작동하고, 왜 믿을 수 있는가

> **대상 독자:** 시스템 사용에 관심 있는 투자자 / 협업자  
> **작성 기준:** 5년 백테스트 (2021~2026, S&P 500 501개 종목, 261거래, --fundamentals 포함)  
> **면책 조항:** 본 시스템은 가상 매매(Paper Trading) 기반의 전략 검증 도구입니다. 과거 수익률은 미래 수익을 보장하지 않습니다.

## 두 가지 전략

이 시스템은 시장 상황에 따라 두 가지 전략을 병행 운용합니다.

### 📉 바닥반등 전략 (Bottom Reversal)

> "이미 많이 빠진 종목이 바닥을 찍고 반등하는 순간을 포착한다"

- 과매도 구간(RSI < 40)의 종목 탐색
- ML 모델이 예측한 단기 저점 확률 활용
- 볼린저 밴드 하단, 지지선 이중 테스트, MACD 다이버전스 확인
- **백테스트 성과:** 115거래, 승률 44.4%, 평균 수익 +0.77%/건

### 🚀 모멘텀 전략 (Momentum)

> "이미 상승 추세가 확인된 종목의 강한 흐름에 올라탄다"

- EMA 정배열(단기 > 중기 > 장기) + ADX > 25 확인
- 거래량 급증 동반 여부 검증 (MA20 × 1.2 이상)
- 섹터 강도 확인 후 진입
- **골든크로스 임박 시그널을 별도 추적**해 페이퍼 트레이딩 이메일에 표기 (2026-05-19~05-22 추가) — 교차 전 진입 기회를 시각적으로 확인할 수 있다.
- **백테스트 성과:** 146거래, 승률 51.4%, 평균 수익 +0.90%/건

## 종목 선정: 7단계 검증 구조

단순히 지표 1~2개로 고르지 않습니다.  
**최대 600개 이상의 후보** 중에서 아래 7단계를 통과해야만 매수 대상이 됩니다.

```
① 전략 점수 필터      — 바닥반등 또는 모멘텀 점수 6.0 이상 (10점 만점)
② 등급 필터          — 스크리너 최상위 등급 종목만
③ 과열 차단          — RSI 75 미만, 볼린저 과열 아님, 5일 급등 아님
④ 유동성 확인        — 일평균 거래대금 $1,000만 이상
⑤ 실적발표 회피      — 어닝 발표 3일 이내 종목 제외
⑥ 중복 보유 방지     — 이미 보유 중인 종목 제외
⑦ 섹터 집중 방지     — 동일 섹터 최대 2종목 이하
```

> 이 7단계를 통과한 종목들을 대상으로 **CCS(종합 확신 점수)** 를 계산, 그 중 1위 종목만 매수합니다.

---

## CCS: 5가지 관점의 종합 평가

종목마다 아래 5가지 관점에서 각각 0~1점을 부여하고 가중합산합니다.

| 평가 항목 | 무엇을 보는가 |
|-----------|--------------|
| **전략 적합도** | 해당 종목이 바닥반등/모멘텀 어느 쪽에 얼마나 잘 맞는가 |
| **진입 타이밍** | RSI, 볼린저, 거래량, MACD 4가지 기술 지표의 진입 타이밍 |
| **알파 팩터** | 5가지 정량 팩터(모멘텀·추세·거래량·변동성·평균회귀)의 합산 |
| **리스크 품질** | ROE, 부채비율, 기관 보유 비율, 공매도 비율, 변동성 수준 |
| **패턴 일치도** | ML 예측 + 반등 스코어 + 일/주/월봉 차트 패턴 동시 확인 |

## 시장 국면 자동 감지

SPY(S&P 500 ETF)의 이동평균선 상태를 매일 확인해 3가지 시장 국면을 자동으로 판단합니다.

| 국면 | 조건 | 전략 대응 |
|------|------|-----------|
| 📈 강세장 (Bull) | SPY > EMA50 > EMA200 | 알파/전략 비중 높여 공격적 운용 |
| ➡️ 중립 (Neutral) | EMA50·200 사이 | 균형 잡힌 안정 기조 |
| 📉 약세장 (Bear) | SPY < EMA200 | 리스크·타이밍 비중 높여 보수적 운용 |

약세장에서는 CCS 최소 기준을 상향하고(0.40 → 0.45), 명시적 매수 신호 없는 종목은 추가로 차단합니다.

## 리스크 관리: 4가지 매도 규칙

진입만큼 **청산 규칙**이 중요합니다. 모든 포지션에 아래 4가지 자동 청산 조건이 적용됩니다.

| 조건 | 기준 | 목적 |
|------|------|------|
| ✅ 목표가 도달 | +15% 이상 | 수익 확정 |
| 🛑 손절 | -5% 이하 | 손실 제한 |
| 🔽 트레일링 스탑 | 고점 대비 -5% | 수익 지키기 |
| ⏱ 장기보유 청산 | 21일 초과 + 수익 < +2% | 기회비용 관리 |

> **Hold-Winners 기능:** +15% 목표가 도달 시, 모멘텀이 강하다고 판단되면 청산을 2회까지 유예하고 타이트한 트레일링 스탑(-3.5%)으로 추가 상승을 추구합니다.

## 자동화 구조

사람이 매일 개입하지 않아도 됩니다.

```
매일 오후 5시 EST (장 마감 후)
    ↓
① S&P 500 + NASDAQ 100 분석 자동 실행
② 전체 시장 (~4,000종목) 스캔
③ 페이퍼 트레이딩 포트폴리오 업데이트 (매수/매도 자동 결정)
④ Google Sheets 자동 업데이트

```

GitHub Actions를 통해 클라우드에서 자동 실행되며, 결과는 Google Sheets와 이메일로 확인할 수 있습니다.

## 현재 한계 (솔직하게)

신뢰는 투명성에서 나옵니다.

- **승률 48.3%** — 절반 이하의 거래가 손실. 단기 연속 손실 구간이 발생할 수 있음
- **MDD -30.8%** — 최악의 시기에는 자산이 30% 이상 감소할 수 있음 (SPY MDD와 유사)
- **가상 매매** — 실제 매매의 세금, 수수료, 슬리피지 완전 반영 안 됨
- **데이터 한계** — yfinance 데이터의 간헐적 오류 가능성
- **과거 성과** — 5년 백테스트가 미래 수익을 보장하지는 않음
