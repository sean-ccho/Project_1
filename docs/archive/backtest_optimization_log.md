# Backtest 성과 최적화 로그

이 문서는 백테스트 파라미터 튜닝 및 전략 개선의 진행 상황을 추적한다.
각 실험마다 변경 내용, 결과, 비교를 기록하여 어떤 변경이 효과적이었는지 판단한다.

---

## Baseline (2026-04-04)

> `scripts/run_sp500_backtest.py --period 3y` | S&P500 전체 | 리밸런스 1일

| 지표 | 값 |
|------|-----|
| 총거래 | 120건 |
| 승률 | 55.0% |
| 평균수익 | +2.01% |
| 평균승리 / 평균손실 | +7.44% / -4.62% |
| 승패비율 | 1.61 |
| 평균보유 | 15.3일 |
| Sharpe | 1.04 |
| **MDD** | **-43.5%** |
| SPY 수익률 | +34.24% |
| 전략 수익률 | +675.52% |

### 전략별 성과 (Baseline)

| 전략 | 거래수 | 승률 | 평균수익 |
|------|--------|------|----------|
| 모멘텀 | 35 | 65.7% | +1.76% |
| 바닥반등 | 23 | 47.8% | +2.35% |
| 전환구간 | 62 | 51.6% | +2.03% |

### Baseline 파라미터

```
STOP_LOSS = 0.05          # -5%
TRAILING_STOP = 0.05      # 고점 대비 -5%
PROFIT_TARGET = 0.15      # +15%
MAX_HOLDING_DAYS = 21     # 3주
STALE_MIN_RETURN = 0.02   # 21일 후 최소 수익률
MAX_POSITIONS = 3
시간익절 = 10일 + 6%
CCS 최소 = 0.35 (normal), 0.45 (bear)
전략점수 최소 = 6.0 (모든 전략 동일)
전환구간 CCS 페널티 = -0.05
```

### Baseline 진단

- **MDD -43.5%**: 실전 운용 불가 수준. 연속 손실 누적 + 베어마켓 방어 부족
- **전환구간 과다**: 전체의 52%, 승률 51.6% — 애매한 신호가 대량 진입
- **바닥반등 falling knife**: 47.8% 승률 — 하락 중 종목에 너무 일찍 진입
- **고정 손절**: 전략 무관하게 -5% 동일 적용

## 개선 계획 (우선순위)

### P1. 전환구간 필터 강화
- [x] 전환구간 CCS 페널티: -0.05 → -0.15
- [x] 전환구간 전략점수 최소: 6.0 → 7.0
- [x] CCS 최소 임계값: 0.35 → 0.40

### P2. 바닥반등 진입 타이밍 개선
- [ ] 5일 수익률 하한 필터: 바닥반등은 5일수익률 > -3% 필수
- [ ] MACD 확인 강화: macd_hist > 0 이어야 full 점수
- [ ] 거래량 확인 강화: vol_z > 1.5 기준 상향

### P3. 동적 청산 로직
- [ ] 전략별 차등 손절 (모멘텀 -4%, 바닥반등 -7%, 전환구간 -4%)
- [ ] 점진적 트레일링 스탑 (수익구간별 -5%/-3%/-2.5%)
- [ ] 포트폴리오 열 차단기 (2개 이상 손실 시 신규 매수 중단)

### P4. 시간 기반 익절 최적화
- [ ] 1차: 10일+6% → 7일+5%
- [ ] 2차 추가: 15일+3%

### P5. 베어마켓 방어 강화
- [ ] 베어마켓 최대 포지션: 2 → 1
- [ ] 베어마켓에서 전환구간 차단
- [ ] 베어마켓 CCS 임계값: 0.45 → 0.50
