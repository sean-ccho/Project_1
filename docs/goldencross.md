# 골든크로스 라벨을 TradingView 차트 선에 맞추기 — 계획

- 작성: 2026-10-22 (온타리오 시간)
- 상태: **계획만. 아직 아무것도 바꾸지 않았다** — 사용자 허락 후 1단계부터 진행
- 목표: 라벨 · 계산 · TradingView 차트가 모두 같은 선을 보게 한다 — 사용자 차트(SeanEMA)의 4개 선
  **주황 EMA10 · 보라 EMA20 · 노랑 EMA100 · 파랑 EMA200**

## 왜 바꾸나

- 사이트·시트·메일의 '골든크로스' 라벨은 우리 프로그램이 계산한다. 그런데 차트에 없는 선을 쓴다
  (주봉 SMA10/40 · 월봉 SMA3/10 · 일봉 EMA20/50, 배당 조정 가격, 진행 중인 봉 포함).
- 그래서 같은 '골든크로스'라는 말이 차트와 다른 뜻이 된다.
  - 예: 2026-10-22 ADBE — 라벨은 '월봉 골든크로스'인데, 월봉 차트는 주황 269.04 < 보라 309.90 (13% 아래, 데드 상태)
  - 2026-10-22 차트추천 종목 중 라벨과 차트가 반대인 것 17건. 2026-10-16 주·월봉 라벨 42개 중 24개가 반대
- 계산 실수는 아니다: 라벨은 정해진 규칙대로 정확히 계산되고(10-11 341/341, 10-16 42/42 재현), 백테스트에 미래 정보도 없다.
  정의가 차트와 다를 뿐이다. 차트 선 기준으로 따로 한 시험(10-16 48가지, 10-22 주·월봉 골든 + 스퀴즈 · 주봉 골든임박)도
  SPY 를 못 이겨서 지금까지의 결론은 바뀌지 않는다.
- 화면만 바꾸면 ★ 점수·PT-1 은 예전 선으로 계속 판단해서 같은 말이 두 뜻이 된다 → **점수까지 전부 바꾼다.**

## 1. 하나로 맞출 기준

| 항목 | 지금 라벨 | **바꾼 뒤** | TradingView 에서 보이는 것 |
|---|---|---|---|
| 골든크로스 · 데드크로스 | 일 EMA20/50 · 주 SMA10/40 · 월 SMA3/10 | **모든 봉: EMA10(주황)이 EMA20(보라)을 뚫음** | 주황선과 보라선이 교차 |
| 골든 · 데드 임박 | 위와 같은 선, 가격 조건 없음 | 같은 두 선, 간격 −5% ~ 0 + 주황선이 오르는 중 + **종가가 주황선 위** | 주황이 보라 바로 아래에서 올라오는 중 |
| 정배열 (완전 · 눌림목 · 형성중) | 주 EMA10/20/50 · 월 EMA3/6/12 | **주황 > 보라 > 노랑 > 파랑** 순서 (선이 없는 신생 종목은 계산 안 함) | 네 선이 위에서부터 차례로 |
| 차트반전 | EMA20/50/200 | 차트 선 EMA20 · 100 · 200 | 보라 · 노랑 · 파랑 |
| 가격 | 배당 조정 | **분할만 반영** | TradingView 기본 (ADJ 꺼짐) |
| EMA 계산 방식 | 첫 값에서 시작 (신생 종목에서 몇 % 차이) | **TradingView 와 같은 방식** (첫 n봉 평균에서 시작, `screener/ma_cross.py` 의 `pine_ema`) | 범례 숫자와 1센트까지 같게 |
| 봉 | 진행 중인 봉 포함 | **끝난 봉 기준** + 진행 중인 봉은 '예고'로 따로 | 차트 마지막 봉 (진행 중) |
| 사이트 · 시트 · 메일 · 매수 메모 | 예전 라벨 | 새 라벨 + 설명 "EMA10(주황) · EMA20(보라)" | — |
| ★ 점수 · CCS · PT-1 | 예전 라벨로 계산 | 새 라벨로 계산 (가중치는 그대로) | — |
| 캡처 레이아웃 (SeanEMA) | EMA 10·20·100·200, ADJ 꺼짐 | **그대로** (바꿀 것 없음) | 지금 보는 차트 |
| 사이트 위젯 (전체분석) | EMA 10·20·100·200 (MA Ribbon) | 그대로 두고, 선 색을 캡처와 같은 주황 · 보라 · 노랑 · 파랑으로 확인 | 캡처와 같은 선 |

## 2. 진행 순서

| 단계 | 할 일 | 확인 방법 | 시간 |
|---|---|---|---|
| 1 | 스크리너 라벨 계산을 위 기준으로 교체 (TradingView 와 같은 계산 코드는 이미 있음) | 단위 테스트 | 반나절 |
| 2 | TradingView 값과 대조 | 캡처 범례 숫자 읽기(`scripts/tv_legend_check.py`)로 S&P + 나스닥 샘플 대조, 끝난 봉 100% 일치가 목표 | 1~2시간 |
| 3 | PT-1 영향 확인 | 연구 캐시 재계산 + PT-1 10년 백테스트 전후 비교 (결과 보기 전에 기준 등록) | 서버에서 하룻밤 |
| 4 | 사이트 · 시트 · 메일 표시 교체 | 배지 · 필터 · 정렬 · 메모 문구 · 설명. 사이트 e2e 테스트 | 반나절 |
| 5 | 결과 보고 → 허락 → 푸시 | 밤 실행(01:00 ET) 전 푸시, 시트에 'PT-1 규칙 변경일' 표시 | 허락 후 |

## 3. 정할 것

| 질문 | 추천 | 이유 |
|---|---|---|
| 일봉도 같이 바꿀지 | **같이 바꿈** | 다 맞게 보이려면 일봉도 같은 선이어야 한다. 대신 일봉 EMA10·20 은 교차가 잦아서 (종목당 1년에 약 5번) 골든 배지가 자주 뜬다 |
| 3단계에서 PT-1 이 확실히 나빠지면 | **멈추고 다시 상의** | '비슷함'이면 통일을 위해 진행하고, 확실히 나빠지면 점수 가중치를 먼저 다시 본다 |

## 참고

- 2026-10-16 비슷한 시험 (PT-1 엔진에 차트 기준 라벨): Sharpe 0.62 → 0.57 (차이 −0.05, 범위 −0.43 ~ +0.26 — 운과 구분 안 됨),
  거래 약 1/3 이 달라짐 ([MA_CROSS_REPORT.md](quant_improvement/tier3/MA_CROSS_REPORT.md) F3).
- EMA 는 SMA 보다 0~12봉(대부분 1~4봉) 먼저 교차하지만 바로 되돌리는 가짜 신호가 약 2배 (일봉 20/50: 19% vs 9%).
  골든크로스가 뜰 때 이미 오른 정도(가운데값): 주봉 EMA10/20 +16%, 월봉 EMA10/20 +34% — 오른 뒤 확인해 주는 신호다.
- 골든크로스는 사는 신호보다 추세 확인용으로 쓰는 게 일반적이다. '가장 좋은 설정'을 찾는 시험은 과거 운을 찾는 일이라 하지 않는다.
- 다른 길: 기관이 가장 많이 보는 설정(주봉 10주·40주 = 일봉 50·200일)으로 라벨을 두고 TradingView 차트에 그 선을 추가하는 방법.
  어느 쪽이든 라벨과 차트 선을 같게 맞추는 게 핵심이다.
