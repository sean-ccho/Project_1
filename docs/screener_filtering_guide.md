# 스크리너 가이드 (필터링 + 계산 원리)

> 구글 시트에서 좋은 종목을 찾는 실전 가이드 + 점수 계산 방식 레퍼런스.
> 과거 `strategy_calculation_overview.md` 통합본.

## 0. 전략구분 컬럼 — 가장 먼저 확인

시트는 **전략구분** 기준으로 자동 정렬되어 있다. 위에서부터 읽으면 된다.

> 동일 전략구분 내에서는 `바닥반등_적합도 ↓ → 모멘텀_적합도 ↓` 순서로 정렬된다 (`signals.py:476-481`, 2026-05-19 변경 — 기존 모멘텀 우선에서 바닥반등 우선으로 전환).

| 전략구분 | 의미 | 우선순위 |
|---|---|---|
| 🔄 전환구간 | 바닥반등 + 모멘텀 **둘 다** ★★★★★ | ⭐ 최우선 매수 후보 |
| 📉 바닥반등 | 바닥반등만 ★★★★★, 모멘텀은 낮음 | 반등 초기 단계 |
| 📈 모멘텀 | 모멘텀만 ★★★★★, 바닥반등은 낮음 | 상승 추세 진행 중 |
| — | 양쪽 다 낮음 | 신호 없음 — 스킵 |

> **🔄 전환구간**이 가장 중요하다. 바닥을 찍고 모멘텀으로 전환되는 구간으로, 리스크 대비 수익률이 가장 높은 진입 타이밍이다.

## 1. 핵심 필터링 레시피

### 레시피 A-0: 전환구간 (최우선 매수 후보)

> "바닥을 막 찍고 모멘텀으로 올라오는 중 — 타이밍이 가장 좋은 종목"

| 필터 | 조건 |
|---|---|
| `전략구분` | 🔄 전환구간 |
| `RSI` | 35~55 (바닥에서 회복 중) |
| `거래량Z(20)` | > 0 |
| `섹터강도` | ❌ 약함 아닌 것 |

**추가 확인:**
- 주봉패턴에 "이중바닥" 또는 "역헤드앤숄더" → 반전 확인된 전환
- 주봉패턴에 "정배열(형성중)" 또는 "골든크로스임박" → 모멘텀 막 시작

---

### 레시피 A: 바닥반등 최적 후보 (역발상 매수)

> "떨어질 만큼 떨어졌고, 반등 신호가 나오기 시작한 종목"

| 필터 | 조건 |
|---|---|
| `전략구분` | 📉 바닥반등 |
| `바닥반등_적합도_표시` | ★★★★☆ 이상 (4.0+) |
| `RSI` | 30~45 (과매도 탈출 구간) |
| `주봉패턴` 또는 `월봉패턴` | "이중바닥" 또는 "역헤드앤숄더" 또는 "하락쐐기" 포함 |
| `거래량Z(20)` | > 0 (평균 이상 거래량 = 관심 유입) |
| `섹터강도` | ❌ 약함 아닌 것 |

**보너스 조건 (있으면 더 좋음):**
- `공매도%` > 10% → 반등 시 숏커버링으로 상승 가속
- `기관보유%` > 50% → 기관이 이미 검증한 종목
- `일봉패턴`에 "강세잉걸핑" 또는 "모닝스타" 포함

---

### 레시피 B: 모멘텀 추격 (추세 따라가기)

> "이미 오르고 있고, 계속 오를 가능성이 높은 종목"

| 필터 | 조건 |
|---|---|
| `전략구분` | 📈 모멘텀 |
| `모멘텀_적합도_표시` | ★★★★☆ 이상 (4.0+) |
| `주봉패턴` | "정배열(완전)" 또는 "정배열(눌림목)" 포함 |
| `RSI` | 50~70 (건강한 상승 구간) |
| `거래량Z(20)` | > 0 |
| `섹터강도` | ❌ 약함 아닌 것 |

**보너스 조건:**
- `월봉패턴`에도 "정배열(완전)" → 장기 추세까지 완전히 정렬된 가장 강한 종목
- `일봉패턴`에 "골든크로스" 또는 "골든크로스임박" → 단기 추세 전환 확인
- `기관보유%` > 60% → 기관도 함께 올라타는 중

---

### 레시피 C: 숏스퀴즈 후보

> "공매도 세력이 많이 쌓여 있어서, 반등 시 폭발적 상승 가능"

| 필터 | 조건 |
|---|---|
| `공매도%` | > 15% |
| `바닥반등_적합도_표시` | ★★★☆☆ 이상 (3.5+) |
| `RSI` | < 45 (아직 과매수 아닌 상태) |
| `거래량Z(20)` | > 1.0 (거래량 급증 시작) |

**주의:** 공매도가 높다는 건 하락 베팅도 많다는 뜻 — 반드시 반등 신호(바닥반등 별점, 패턴)와 함께 봐야 함

---

### 레시피 D: 안정적 우량주 (배당 + 상승추세)

> "안정적이면서도 상승 중인 우량주"

| 필터 | 조건 |
|---|---|
| `모멘텀_적합도_표시` | ★★★☆☆ 이상 (3.5+) |
| `주봉패턴` | "정배열(완전)" 또는 "정배열(눌림목)" 포함 |
| `기관보유%` | > 60% |
| `공매도%` | < 5% |
| `RSI` | 40~65 |

## 2. 컬럼별 빠른 해석표

### 별점 (가장 중요!)

| 컬럼 | 좋은 값 | 나쁜 값 | 설명 |
|---|---|---|---|
| `전략구분` | 🔄 전환구간 | — | 자동 분류 라벨. 시트 정렬 기준 |
| `바닥반등_적합도_표시` | ★★★★★ (5.0+) | ☆☆☆☆☆ (2.0 미만) | 바닥에서 반등할 가능성. 반전형 패턴에 높은 가중치 |
| `모멘텀_적합도_표시` | ★★★★★ (5.0+) | ☆☆☆☆☆ (2.0 미만) | 상승 추세 지속 가능성. 추세형 패턴에 높은 가중치 |

> **두 별점이 동시에 높으면 🔄 전환구간**으로 분류된다. 바닥→모멘텀 전환 구간으로 가장 좋은 진입 타이밍. 패턴 점수가 캡(3.0)으로 제한되어 있기 때문에, 양쪽 다 5.0+가 나오려면 전략 고유 신호도 함께 충족된 것이다.

### RSI (과매수/과매도 판단)

| RSI 구간 | 의미 | 전략 |
|---|---|---|
| **< 30** | 과매도 (극단적 하락) | 바닥반등 후보 — 단, 하락 이유 확인 필요 |
| **30~45** | 과매도 탈출 중 | 바닥반등 최적 진입 구간 |
| **45~55** | 중립 | 방향 미확정 |
| **55~70** | 건강한 상승 | 모멘텀 전략 최적 구간 |
| **70~75** | 과매수 진입 | 바닥반등은 진입 금지. **모멘텀 전략은 허용** (ADX·거래량 동반 시 추세 지속 가능) — 이메일에 매수 근거 자동 표시 |
| **> 75** | 하드 컷오프 | 전략 무관 매수 금지 |
| **> 80** | 극과매수 | 조정 임박 가능성 높음 |

### 거래량Z(20)

| 값 | 의미 |
|---|---|
| **> 2.0** | 거래량 폭발 — 큰 이벤트 발생 (실적, 뉴스 등) |
| **> 1.0** | 평소보다 뚜렷하게 많음 — 관심 급증 |
| **0 ~ 1.0** | 평균 이상 — 약간의 관심 |
| **< 0** | 평균 이하 — 시장 관심 적음 |
| **< -1.0** | 거래량 크게 감소 — 관심 이탈 |

### 기관보유% / 공매도% / 내부자(90일)

| 컬럼 | 좋은 신호 | 경고 신호 |
|---|---|---|
| `기관보유%` | > 50%: 기관 검증 완료 | < 20%: 개인 주도, 변동성 큼 |
| `공매도%` | < 5%: 하락 베팅 거의 없음 | > 15%: 대규모 하락 베팅 OR 스퀴즈 기회 |
| `공매도주수` | 공매도%와 함께 봐야 규모 파악 가능 | 같은 15%라도 대형주 vs 소형주는 영향이 다름 |
| `내부자(90일)` | 클러스터 매수 다수 = 임원진 확신 | 매도만 다수 = 회피 |

> **내부자(90일)는 표시 전용** — 점수에 반영되지 않는다. `screener/insider.py::attach_insider_summary()`가 openinsider에서 90일 윈도우 거래를 가져와 시트·이메일에만 첨부한다 (2026-05-22 추가).

### 볼린저 P밴드 / 변동성

| 컬럼 | 값 | 의미 |
|---|---|---|
| `볼린저 P밴드` | 0에 가까움 | 하단밴드 근처 → 과매도, 바닥반등 후보 |
| | 0.5 근처 | 중간 → 중립 |
| | 1에 가까움 | 상단밴드 근처 → 과매수 주의 |
| `변동성압축` | < 0.8 | 변동성 축소 중 → 큰 움직임 임박 가능 |
| | > 1.5 | 변동성 과다 → 위험 구간 |

## 3. 패턴 컬럼 읽는 법

### 일봉패턴 (단기 신호)

| 패턴 | 의미 | 활용 |
|---|---|---|
| **도지** | 매수/매도 힘 균형 → 추세 전환 가능 | 하락 후 도지 = 반등 신호 |
| **강세잉걸핑** | 전일 음봉을 완전히 감싸는 양봉 | 강한 반등 신호 |
| **모닝스타** | 3일 패턴: 하락→소형캔들→상승 | 바닥 확인 신호 |
| **골든크로스** | SMA50이 SMA200을 상향 돌파 | 상승추세 시작 |
| **골든크로스임박** | SMA50/200 갭 2% 이내 + 수렴 중 + **단기 MA가 장기 MA 아래에 50봉 이상 지속** | 미리 주시할 종목 (2026-05-18 sustained-below 검증 추가) |
| **데드크로스** | SMA50이 SMA200을 하향 돌파 | 하락추세 시작 — 회피 |
| **상승삼각형** | 고점은 같고 저점은 높아지는 형태 | 상방 돌파 임박 |
| **이중바닥** | 비슷한 가격에서 두 번 바닥 → W자 형태 | 강한 지지 확인, 반등 유력 |
| **역헤드앤숄더** | 세 개의 바닥 중 가운데가 가장 낮음 | 클래식 반전 패턴 |
| **컵앤핸들** | U자 회복 후 소폭 조정 | 상승 지속 패턴 |
| **하락쐐기** | 고점·저점 모두 낮아지지만 수렴 중 | 상방 돌파 임박 (역설적 상승 신호) |

### 주봉패턴 / 월봉패턴 (중장기 신호)

> 주봉·월봉 패턴은 일봉보다 **신뢰도가 훨씬 높다**

| 패턴 | 우선순위 | 설명 |
|---|---|---|
| **정배열(완전)** | ★★★ 최우선 확인 | Price > EMA10 > EMA20 > EMA50 완전 정렬. 가장 강한 상승 상태 |
| **정배열(눌림목)** | ★★☆ 좋은 매수 타이밍 | EMA 정렬은 살아있고 가격이 단기 눌림. EMA10 아래지만 EMA20 위 |
| **정배열(형성중)** | ★☆☆ 초기 신호 | EMA10 > EMA20 정렬 시작, EMA50은 아직 미정렬. 관심 종목 편입 |
| **골든크로스** | ★★★ | 주봉/월봉 골든크로스는 대세 상승 전환 신호 |
| **이중바닥** | ★★☆ | 큰 타임프레임의 W 바닥 → 강력한 지지 |
| **역헤드앤숄더** | ★★☆ | 큰 타임프레임 반전 → 대세 전환 |
| **하락쐐기** | ★★☆ | 장기 하락 속 수렴 → 반등 준비 |

**핵심 팁:** 주봉·월봉 모두 "정배열(완전)"이면 가장 강한 상승 신호. "정배열(눌림목)"은 이미 오른 종목의 눌림 구간으로 매수 타이밍 포착에 활용.

## 4. 컬럼 조합 해석

### 기관 + 공매도 조합

| 기관보유% | 공매도% | 해석 |
|---|---|---|
| 높음 (>50%) | 낮음 (<5%) | 기관이 Long 확신, 가장 안정적 |
| 높음 (>50%) | 높음 (>15%) | 기관 vs 숏셀러 대립 — 방향 결정 시 큰 움직임 |
| 낮음 (<20%) | 낮음 (<5%) | 시장 관심 낮음, 조용한 종목 |
| 낮음 (<20%) | 높음 (>15%) | 투기적, 고위험 — 반등 시 폭발적이지만 하락도 클 수 있음 |

### 전략구분 + 두 별점 조합

| 전략구분 | 바닥반등 | 모멘텀 | 해석 |
|---|---|---|---|
| 🔄 전환구간 | ★★★★★ | ★★★★★ | 바닥→모멘텀 전환 중. **최우선 매수 후보** |
| 📉 바닥반등 | ★★★★★ | ★★★☆☆ 이하 | 아직 하락 추세지만 반등 신호 강함. 선제 진입 |
| 📈 모멘텀 | ★★★☆☆ 이하 | ★★★★★ | 이미 오르고 있고 추세 강함. 눌림목 대기 |
| — | ★★★☆☆ 이하 | ★★★☆☆ 이하 | 신호 없음 — 스킵 |

### RSI + 패턴 + 거래량 조합 (바닥반등용)

| RSI | 패턴 | 거래량Z | 해석 |
|---|---|---|---|
| 30~40 | 이중바닥/역헤드앤숄더 | > 1.0 | **최고의 바닥반등 후보** — 과매도 + 반전 패턴 + 거래량 확인 |
| < 30 | 없음 | < 0 | 아직 낙하 중 — 바닥 확인 전까지 대기 |
| 30~40 | 강세잉걸핑/모닝스타 | > 0 | 좋은 후보 — 단기 반전 신호 |

### 추세 확인 조합 (모멘텀용)

| 주봉패턴 | 월봉패턴 | RSI | 해석 |
|---|---|---|---|
| 정배열(완전) | 정배열(완전) | 55~70 | **최고의 모멘텀 후보** — 모든 타임프레임 완전 정렬 |
| 정배열(눌림목) | 정배열(완전) | 45~60 | **눌림목 매수 기회** — 장기는 강하고 단기만 쉬는 중 |
| 정배열(완전) | 정배열(눌림목) | 55~70 | 중기 추세 강하고 장기도 회복 중 |
| 정배열(형성중) | 정배열(완전) | 50~65 | 새로운 상승 시작 — 초기 진입 기회 |
| 골든크로스 | 정배열(완전) | 50~65 | 단기 골든크로스 + 장기 정배열 — 강한 진입 신호 |

## 5. 주의사항 / 함정

### 높은 별점이어도 조심해야 할 경우

| 상황 | 이유 | 확인 방법 |
|---|---|---|
| 별점 높은데 `섹터강도` ❌ 약함 | 해당 섹터 전체가 하락 중이면 개별 종목도 영향 받음 | 섹터강도 컬럼 확인 |
| `RSI` > 75인데 모멘텀 별점 높음 | 이미 과매수 → 조정 올 수 있음 | RSI 컬럼 확인 |
| 패턴은 좋은데 `거래량Z` < -1 | 거래량 없는 패턴은 신뢰도 낮음 | 거래량Z(20) 확인 |
| `공매도%` > 20% | 극단적 숏 포지션 → 스퀴즈 가능성도 있지만 그만큼 하락 리스크도 큼 | 반드시 다른 지표와 함께 판단 |
| 바닥반등 별점 높은데 `5일수익률` > 20% | 이미 급등한 종목 — 추격 매수 위험 | 수익률 컬럼 확인 |

### 절대 하지 말아야 할 것

- **별점 하나만 보고 매수** — 반드시 RSI, 패턴, 거래량을 교차 확인
- **바닥반등 + 모멘텀 둘 다 ☆☆☆☆☆인 종목에 투자** — 시스템이 어떤 신호도 감지 못한 것
- **데드크로스 패턴 무시** — 특히 주봉/월봉 데드크로스는 강한 하락 신호
- **거래량 무시** — 거래량이 뒷받침되지 않는 가격 움직임은 지속되지 않음

## 6. 빠른 체크리스트

시트를 열었을 때 순서대로 확인:

1. **전략구분 확인** — 시트는 이미 🔄 전환구간 → 📉 바닥반등 → 📈 모멘텀 순으로 정렬되어 있음
2. **🔄 전환구간 우선 검토** — 가장 위에 있는 종목들, 양쪽 별점 모두 확인
3. **★★★★☆ 이상 필터** — 4.0점 이상만 남기기
4. **주봉/월봉 패턴 확인** — 전략구분에 맞는 패턴인지 (바닥: 이중바닥/역헤드앤숄더 / 모멘텀: 정배열/골든크로스)
5. **RSI 확인** — 전략에 맞는 구간인지 (전환: 35~55 / 바닥: 30~45 / 모멘텀: 50~70)
6. **거래량Z > 0 확인** — 시장 관심이 있는 종목인지
7. **기관보유% / 공매도% 참고** — 추가 확신 또는 리스크 판단
8. **섹터강도 확인** — 약한 섹터는 주의

# 📐 Part 2: 점수 계산 원리

> 위 필터링이 "무엇을 볼지"라면, 이 섹션은 "점수가 어떻게 만들어지는지" 레퍼런스.

## 전체 계산 파이프라인

### [SP500 분석] (`main.py`)
```
OHLCV 5년 → 유동성 필터 → 피처 계산 (30+) → 반등스코어 (5신호)
→ 알파 모델 (5팩터) → 중립화 → 상대강도
→ 전략 점수 (Phase 1~3) → Composite Score 랭킹 + 4단계 최종 필터
→ 별점
```

### [NASDAQ/NYSE 분석] (`run_full_scan.py`) — 3단계 깔때기
```
~4,000개 → [Stage 1] 기본 필터 (주가 $1+, 거래량 100K+)
→ [Stage 2] 후보 선별 (1년 OHLCV, 고속 필터)
   ├ 바닥반등: 52주 고점 -20%+
   └ 모멘텀: 52주 고점 5% 이내 AND 20일 +15%+
→ [Stage 3] 정밀 분석 → 4.0점+ 이메일
```

## 8단계: 최종 랭킹 (Composite Score)

```
Composite(100) = Alpha(35%) + Strategy(35%) + Sharpe(30%)
```

- **Sharpe Proxy**: 20일수익률 / ATR% (리스크 조정)
- **어닝 리스크**: 발표 7일 전 -30% 패널티
- **상관관계 필터**: 상관계수 > 0.75면 점수 낮은 쪽 제거

### 최종 필터링 순서

`Composite → 상위 10% → 원점수 6.0+ → 상관관계 다변화 → 섹터 최대 3 → Top 10`
