# 3단계 PEAD — 3-1 대리 이벤트 (px10y)

- 이벤트: 시가 갭 ≥ 4% & 거래량 ≥ 3× 직전 20일 평균, 그날 S&P 500 구성종목
- 방향: 이벤트일 수익률 − 구성종목 동일가중 의 부호. 진입 t+1 시가 → 청산 t+1+h 시가, 동일가중 대비 초과수익
- 이벤트 3,489건 (상승 1,399 · 하락 2,090), 2016-01-06 ~ 2025-09-30
